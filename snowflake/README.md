# Snowflake-Native Pipeline

This directory contains the future Snowflake-native implementation of the ECMWF TC Forecast Pipeline.

## Overview

The Snowflake-native pipeline will run all processing directly in Snowflake, eliminating the need for external Python execution. This approach offers:

- No external compute required
- Native Snowflake scheduling
- Direct data processing in the database
- Reduced operational overhead

## Status

**This implementation is ongoing.**
